Import puzzles

Three formats, detected automatically:
• PGN (e.g. a Lichess study export): each game with a [FEN] header; theme and rating are read from the chapter name or a comment (e.g. "mateIn1 … rating 1297").
• Lichess puzzle CSV (PuzzleId,FEN,Moves,Rating,…,Themes).
• Simple: FEN;moves in UCI;theme;rating per line.

Alle Sets sind dauerhaft geladen (Startset, Jobava-Linien, Explorer-Linien, Schwarz-Repertoire, Cycles Set 1) – die Buttons stellen ein Set nur wieder her, falls es gelöscht wurde.

Dein Lichess-Set aus cycles/sets/set1, in Study-Reihenfolge (01 leicht → 16 schwer). Für Zyklen: Filter „Set: WP Set1“ setzen und Modus Cycles wählen.

Eröffnungsdrill: Du spielst Weiß ab 3.Lf4, die App antwortet als Schwarz (…g6/…Lg7-Aufbau). Zum reinen Eröffnungstraining oben den Filter „Thema: Jobava-KID“ setzen.

300 Puzzles (1350–1450) aus der Lichess-Datenbank ziehen – Terminal auf dem Mac 
brew install zstd
curl -L -o lichess_db_puzzle.csv.zst https://database.lichess.org/lichess_db_puzzle.csv.zst
zstdcat lichess_db_puzzle.csv.zst | awk -F, 'NR>1 && $4>=1350 && $4<=1450' | shuf -n 300 > set_1350_1450.csv

Die Datei dann hier über „Datei wählen“ laden (Gegnerzug-Häkchen wird für CSV automatisch gesetzt). Für nur Mattaufgaben: grep -i mateIn vor dem shuf einfügen.
